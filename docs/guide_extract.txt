MEDIUMBUG #001: Live Map Filters Non-Responsive 
Step-by-Step Solution:
1. Open Live Map component (e.g., `LiveMap.jsx`).
2. Apply a filter to the array before rendering Leaflet markers:
const filteredInstitutes = institutes.filter(inst => {
  const matchDist = selectedDistrict === 'All districts' || inst.district === selectedDistrict;
  const matchScheme = selectedScheme === 'All schemes' || inst.scheme === selectedScheme;
  return matchDist && matchScheme;
});
LOWBUG #002: CCTV Video Streams Infinite Buffer 
Step-by-Step Solution:
1. Update CCTV feeds component to use reliable public HLS/MP4 test links.
2. Add an `onError` attribute to the video tag to gracefully degrade: e.g., show a "Stream Offline" placeholder image
instead of hanging on a loading spinner.

HIGHBUG #003: MultipartFile Web Crash (`dart:io`) 
Step-by-Step Solution:
1. Open `capture_screen.dart`.
2. Use `kIsWeb` to branch the file upload logic:
import 'package:flutter/foundation.dart';
if (kIsWeb) {
  var bytes = await imageFile.readAsBytes();
  request.files.add(http.MultipartFile.fromBytes('file', bytes, filename: 'upload.jpg'));
} else {
  request.files.add(await http.MultipartFile.fromPath('file', imageFile.path));
}
MEDIUMBUG #004: Alert Resolution vs. Risk Score Sync 
Step-by-Step Solution:
1. Open the Alerts frontend component and locate the `handleResolveAlert` function.
2. Chain a secondary API call to physically update the institute record:
await api.patch(`/alerts/${alertId}`, { status: 'resolved' });
await api.patch(`/institutes/${instituteId}`, { risk_score: 0, status: 'safe' });
